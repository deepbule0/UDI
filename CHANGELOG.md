# Changelog

## 0.2.0 — 2026-10-17

- Added UDI Pocket, an English/Chinese phone demo at `mobile.html`, with five touch navigation tabs and card-based views.
- Reused the desktop package contract, planner, validated session loader, source permissions, and confirmed local actions.
- Added install metadata, home-screen icons, safe-area layout, an offline app-shell cache, and an explicit update control.
- Added phone acceptance and production offline checks, bilingual installation documentation, and phone screenshots.

UDI Pocket is an installable web app. There is no native App Store or Play Store binary. The UDI Core schema remains `0.1`; existing packages remain compatible.

## 0.1.0 — 2026-10-17

Initial experimental proposal and reference prototype.

- Added English and Simplified Chinese documentation, a bilingual demo, and supported Chinese offline intents.

- Added the UDI package–instance lifecycle, position paper, and related-work analysis.
- Added JSON Schemas, semantic validation, and a five-component React renderer.
- Added reviewed bounded revisions, stale-base checks, undo, and browser persistence.
- Added independent fictional datasets, capability controls, and confirmed local-note effects.
- Added validated export/import, local forks, and grant reset on installation.
- Added an offline intent parser and optional local Ollama planner bridge.
- Added conformance cases, core/adapter tests, browser scenarios, CI, and optional Pages deployment.

Live connectors, external writes, workflow automation, production authorization, and protocol adapters are not part of this release.
