# 安全模型与局限

[English](../../SECURITY.md) | **简体中文**

UDI Studio 是运行于虚构演示数据上的研究原型。不要将敏感服务接入这一浏览器策略层，也不要将其控件视为生产授权。

## 资产与信任边界

需要保护的资产包括实例记录、本地笔记、数据源绑定、授权、已审查定义的完整性，以及已批准动作的完整性。不受信任的输入包括导入的包、未来的模型输出、源内容和浏览器持久化状态。宿主拥有组件目录和动作处理器。

原型的宿主、策略代码和演示数据共享同一个浏览器进程。控制该进程的用户或脚本可以查看内置记录，并修改本地存储或代码。能力控制演示了应用行为，无法隔离已经发送到客户端的数据。真实网关必须在可信服务端或同等隔离的进程中执行授权。

## 威胁与已实现的缓解措施

| 威胁 | 已演示的缓解措施 | 剩余边界 |
| --- | --- | --- |
| 包包含可执行代码或未知渲染器 | 封闭的 JSON Schema、拒绝未知字段、固定 React 组件、不使用 `eval` 或原始 HTML 渲染器 | 仍需信任获准组件的代码及依赖 |
| 包替换其他数据源的能力 | 实体与能力兼容性检查，以及声明检查 | 真实适配器的结果需要验证，并检查资源范围 |
| 能力请求悄悄变成访问权限 | 授权属于各实例本地；新增请求不改变授权 | 浏览器授权可编辑，也不构成真实服务授权 |
| 没有明确预览就发生写入 | 精确的本地笔记预览和单独确认；执行时重新检查定义、实例、数据与授权 | 确认不是签名授权或单次授权；没有防重放机制 |
| 过期的智能体提案修改了已演变的工作区 | 比较基准修订号和稳定序列化的精确定义；原子性验证候选结果 | 没有多用户事务或跨标签页冲突解决 |
| 共享导出包含工作区记录或令牌 | 导出仅接受严格的规范结构 | 自由文本元数据可能泄漏秘密或个人信息 |
| 提示词注入改变策略 | 模型输出被限制为经过验证的操作；模型不能提供授权或处理器 | 有效操作仍可能不符合期望；需要人工审查 |
| 远程网页使用本地模型桥接服务 | 仅监听回环地址、检查 Host/Origin、仅接受 JSON POST；不启用宽松 CORS | 信任其他本地进程；未针对多用户托管进行加固 |
| 过大包耗尽导入资源 | 64 KiB 包上限，有界的数组与字符串 | 不是通用的拒绝服务防护 |

## 凭据与网络行为

静态演示没有账户凭据、分析统计、外部连接器调用或后台工作进程。字体随应用打包。可选的开发桥接服务接受定义和意图，并将其发送到 `127.0.0.1:11434` 上的 Ollama；请求契约不包含记录、本地笔记、绑定 ID 和授权。自由文本意图和元数据仍可能敏感。桥接服务没有远程模型回退，也不能接收调用者指定的模型端点。

可选模型是由运行者自行管理的依赖。传输验证测试不能证明模型行为，也不能证明系统能够抵御已被入侵的本地运行时。

## 持久化与审计

应用将状态保存在浏览器本地存储的 `udi-studio:0.1` 项下。重置会清除此应用的演示状态。应用不会加密数据。本地活动日志有长度限制且可被编辑，并非防篡改的审计记录。撤销恢复的是界面定义，不会撤销能力或逆转操作效果。两个标签页可能相互覆盖持久化状态。

## 用于生产环境之前

生产系统需要：保管凭据的网关、已认证用户、每次操作的资源范围策略、适配器输出验证、并发控制、与载荷和有效期绑定的批准令牌、副作用幂等性、经过加固的内容策略、导出审查、包供应链模型，以及独立安全评估。这些是架构要求，不是已实现的功能。
