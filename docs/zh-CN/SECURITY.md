# 安全模型与局限

[English](../../SECURITY.md) | **简体中文**

UDI Studio 是运行于虚构演示数据上的研究原型。不要将敏感服务接入这一浏览器策略层，也不要将其控件视为生产授权。

[通用框架](FRAMEWORK.md)定义更广的目标。当前 Core 0.1 研究配置仅在本地演示边界，尚未实现生产平台集成。

## 直接分享与采用

系统分享／复制链接只把严格校验的定义序列化到 URL 片段，不上传到 UDI 服务器。URL 片段不会随普通 HTTP 请求发送，但浏览器扩展、页面脚本、历史记录或使用者选择的分享应用可能看到链接。持有链接的人可以解码公开名称、描述与定义字段。请检查自由文本；该机制不提供保密、签名、作者认证、托管短链接或撤回服务。之后修改体验不会更新已经发出的副本，撤下社区帖子也无法收回副本。

创建链接排除记录、笔记、绑定 ID、授权、聊天与活动。规范 base64url、16,000 字符的 URL／片段上限、64 KiB 有界解压、严格 UTF-8 解码、Schema 与语义检查限制传入定义。应用在异步解析前移除地址栏中的定义片段。打开链接只展示公开虚构示例记录，不应用更改或读取私人实例。明确选择**使用**才会重新校验定义、保留记录与笔记、清空每个实例的授权并打开数据审阅。预览中的操作按钮禁用。这些措施不认证发送者，也不证明定义有用。

系统分享和剪贴板写入仅在使用者明确操作后发生。链接分享与公开社区上架分开，GitHub 发布仍为高级流程，需要人最终提交。**创建我的工作空间**在本地保存经过校验的研究记录，初始无授权；明确允许读取只授予所请求的读取能力，不会自动授予笔记写入。

## 资产与信任边界

需要保护的资产包括实例记录、本地笔记、数据源绑定、授权、已审查定义的完整性，以及已批准动作的完整性。不受信任的输入包括导入的包、未来的模型输出、源内容和浏览器持久化状态。宿主拥有组件目录和动作处理器。

原型的宿主、策略代码和演示数据共享同一个浏览器进程。控制该进程的用户或脚本可以查看内置记录，并修改本地存储或代码。能力控制演示了应用行为，无法隔离已经发送到客户端的数据。真实网关必须在可信服务端或同等隔离的进程中执行授权。

## 威胁与已实现的缓解措施

| 威胁 | 已演示的缓解措施 | 剩余边界 |
| --- | --- | --- |
| 包包含可执行代码或未知渲染器 | 封闭的 JSON Schema、拒绝未知字段、固定 React 组件、不使用 `eval` 或原始 HTML 渲染器 | 仍需信任获准组件的代码及依赖 |
| 包替换其他数据源的能力 | 实体与能力兼容性检查，以及声明检查 | 真实适配器的结果需要验证，并检查资源范围 |
| 能力请求悄悄变成访问权限 | 授权属于各实例本地；新增请求不改变授权 | 浏览器授权可编辑，也不构成真实服务授权 |
| 没有明确预览就发生写入 | 精确的本地笔记预览和单独确认；执行时重新检查定义、实例、数据与授权 | 确认不是签名授权或单次授权；没有防重放机制 |
| 过期的智能体提案修改了已演变的工作区 | 比较基准修订号和稳定序列化的精确定义；原子性验证候选结果 | 没有多用户事务或跨标签页冲突解决 |
| 共享导出包含工作区记录或令牌 | 导出仅接受严格的规范结构 | 自由文本元数据可能泄漏秘密或个人信息 |
| 提示词注入改变策略 | 模型输出被限制为经过验证的操作；模型不能提供授权或处理器 | 有效操作仍可能不符合期望；需要人工审查 |
| 远程网页使用本地模型桥接服务 | 仅监听回环地址、检查 Host/Origin、仅接受 JSON POST；不启用宽松 CORS | 信任其他本地进程；未针对多用户托管进行加固 |
| 过大包耗尽导入资源 | 64 KiB 包上限，有界的数组与字符串 | 不是通用的拒绝服务防护 |

## 凭据与网络行为

静态演示没有账户凭据、分析统计、外部连接器调用或后台账号自动化。生产版本的 Service Worker 会缓存公开应用资源，供离线使用。字体随应用打包。可选的开发桥接服务接受定义和意图，并将其发送到 `127.0.0.1:11434` 上的 Ollama；请求契约不包含记录、本地笔记、绑定 ID 和授权。自由文本意图和元数据仍可能敏感。桥接服务没有远程模型回退，也不能接收调用者指定的模型端点。

可选模型是由运行者自行管理的依赖。传输验证测试不能证明模型行为，也不能证明系统能够抵御已被入侵的本地运行时。

## 持久化与审计

应用将状态保存在浏览器本地存储的 `udi-studio:0.1` 项下。重置会清除此应用的演示状态。应用不会加密数据。本地活动日志有长度限制且可被编辑，并非防篡改的审计记录。撤销恢复的是界面定义，不会撤销能力或逆转操作效果。两个标签页可能相互覆盖持久化状态。

手机 PWA 的 Service Worker 作用域限定在部署目录，缓存公开构建产物及其中的虚构预置数据，不缓存 API 响应，也不通过该缓存保存本地授权、笔记或导入的定义；这些状态仍保存在 localStorage 中。添加到主屏幕和离线能力不会增加授权边界。缓存可能在更新前保留旧版本，浏览器存储也可能被清除或回收。重置演示不会删除 Service Worker 缓存；清除网站数据会删除本地状态和缓存资源。桌面和手机入口仅在同一来源与存储环境内共享状态；iPhone 主屏幕网页应用与 Safari 相互隔离。没有设备同步功能。详见[手机使用指南](MOBILE.md)。

## 社区与个人数据

社区以不含凭据及来源引用的匿名 GET 请求读取公开仓库的 GitHub Issues API。仅接受带指定标记、标签、处于公开未关闭状态且包含一份通过 Schema 校验的 JSON 包的帖子；链接由固定仓库与 Issue 编号构造，文本不作为 Markdown 或 HTML 执行。通过校验的定义仍不可信，安装会清除所有实例授权。公开动态缓存与个人记录分开，可能过期或因限流而不可用。

发布流程将定义放入待审核的 GitHub 编辑器链接；较大的包使用复制粘贴正文。应用不持有 GitHub 凭据，打开编辑器不等于发布，使用者必须在 GitHub 登录并提交。公开自由文本与简介仍需人工隐私检查。导入记录、授权、笔记、绑定及对话历史不会自动发送到社区，但用户自己填写的自由文本仍可能包含私人信息。

个人 JSON 经过严格校验和独立命名后，作为未加密的浏览器本地记录保存，导入时不授予权限。个人数据下载是独立的仅记录操作。确认删除会移除该数据集及其实例授权和笔记；重置还会清除个人导入记录及本地最近 40 条对话。用户输入的指令本身可能包含私人文本；可选本地模型桥接接收所提交的提示词与界面包定义，不会自动发送记录或完整对话历史。

## 生产要求

生产系统需要：保管凭据的网关、已认证用户、每次操作的资源范围策略、适配器输出验证、并发控制、与载荷和有效期绑定的批准令牌、副作用幂等性、经过加固的内容策略、导出审查、包供应链模型，以及独立安全评估。这些是架构要求，不是已实现的功能。

## 报告问题

配置公开仓库和私密报告联系方式后，请使用该仓库的私密安全报告渠道。在此之前，不要在公开 Issue 中包含真实秘密、私人记录，或影响真实服务的漏洞利用细节。本仓库不虚构维护者邮箱。
