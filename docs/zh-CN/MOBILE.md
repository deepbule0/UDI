# UDI Pocket 手机应用演示

[English](../MOBILE.md) | **简体中文**

[用中文打开](https://deepbule0.github.io/UDI/mobile.html?lang=zh-CN) · [Open in English](https://deepbule0.github.io/UDI/mobile.html?lang=en) · [桌面演示](https://deepbule0.github.io/UDI/?lang=zh-CN)

UDI Pocket 让人们像平常一样使用应用，再让智能体调整受支持的行为和呈现方式，或试用他人分享的使用方式并变成自己的。分享时只需链接，无需处理 API 或定义文件。手机演示采用卡片布局和底部导航，可在支持的手机上作为渐进式网页应用（PWA）添加到主屏幕。

这是一个实验性网页应用，尚未提供 App Store 或 Google Play 安装包。它与 UDI Studio 使用相同的界面包格式、校验器、规划器、能力检查和操作确认规则。

[UDI 框架](FRAMEWORK.md)是面向可复用应用体验的通用提案，涵盖呈现形式、受支持的行为和数据组织。当前应用只实现研究工作空间配置 Core 0.1。音乐、阅读等应用类别是说明性场景；演示尚未实现这些提供方服务集成。

底部导航包括**首页**（工作区卡片）、**智能体**（对话和设置式控制面板）、**数据**（平台与个人数据集、授权和笔记）、**社区**（公开界面帖子、项目示例和界面包工具）和**活动**（本地历史）。

## 体验完整流程

1. 打开手机演示，通过 **EN / 中文** 切换语言。工作区以卡片展示虚构的实验记录，同时提供指标、模型对比和截止日期。
2. 打开**智能体 → 对话**，发送**只显示失败实验**。检查生成的提案；只有点击**应用更改**，当前工作区才会改变。**控制面板**提供布局、面板显示、数据源绑定和权限等设置式选项，也会先生成待审阅的更改。
3. 回到**首页**，查看某次实验记录的提交。这是虚构数据中通过明确 ID 关联的溯源信息，没有连接真实 GitHub 仓库。
4. 将实例从 **Aurora lab** 切换为 **Atlas lab**。界面定义保持不变，绑定的记录和各实例的授权分别独立。**撤销**会恢复上一份界面定义，同时保留当前的数据绑定。
5. 在**智能体**中尝试**添加相关论文**或**添加审阅笔记操作**。添加操作会声明对 `notes.write` 的请求，不会自动授权。在**智能体**中提出授权，或在**数据**中为当前实例启用该能力后，还需从**首页**预览并单独确认笔记的具体内容，才会写入本地。笔记保存在当前浏览器存储环境中。对话也支持明确的数据源和权限指令，例如**切换到 Atlas lab**、**撤销实验访问权限**。
6. 在**数据**中选择**创建我的工作空间**，填写工作空间名称，以及一条实验的名称、模型、状态和分数，无需文件。新工作空间**不自动授予任何权限**；可选择**允许读取此工作空间**或逐项设置。JSON 导入与仅记录备份属于可选的**高级数据工具**，删除需要另行确认。表单只创建首次记录，尚不是完整记录编辑器。
7. 打开**社区**，浏览公开界面帖子或项目示例。**试试这个界面**会使用公共示例记录呈现真实预览。**使用这个界面**或**复制并使用**会替换定义，并清除所有本地实例的授权。记录和笔记保留，接下来由你选择工作空间与访问权限。
8. 在**首页**选择**分享这个界面**，或在社区选择**分享我的界面**。检查名称、介绍和隐私说明后，选择**分享…**或**复制链接**。接收者会看到示例数据预览，必须明确点击**使用这个界面**才能应用。仅打开链接不会修改任何内容。无需账户、上传、文件或 JSON。详见[社区指南](COMMUNITY.md)。

托管版智能体使用小型确定性解析器，接受支持范围内的中文和英文指令。应用加载后，它在设备上运行，无需 API 密钥，也不会调用语言模型。不支持的请求会明确报错。智能体通过待审阅提案修改界面定义、绑定和授权；不会自主导入、删除或发布数据。内置数据集与论文标题均为虚构内容。本地表单和高级导入只支持文档规定的研究记录，不支持任意应用数据。没有真实账号数据连接器、音乐播放、推送通知、摄像头访问或后台外部操作。

社区在可用时读取真实的公开 GitHub 帖子，并明确标记缓存内容或获取失败。内置卡片标记为 **UDI 项目示例**，不代表其他用户已经发帖。浏览和直接链接分享无需登录。创建公开条目则使用独立的**高级发布 → 发布到公开社区**流程：审阅内容，打开 GitHub 编辑器，登录后在 GitHub 提交。只打开编辑器不会发布，复制链接也不会创建公开条目。应用不会保存 GitHub Token。

## 添加到手机主屏幕

先在手机的常规浏览器中打开演示。点击顶部的问号按钮，打开**关于与安装**，可查看安装说明和缓存状态。安装菜单因浏览器和系统版本而异；也可以直接在网页中使用。

### Android 与 Chrome

1. 在 Chrome 中打开 [UDI Pocket](https://deepbule0.github.io/UDI/mobile.html?lang=zh-CN)。
2. 打开 Chrome 的**更多**菜单，选择**安装并创建快捷方式 → 安装**。部分版本的菜单名称可能是**安装应用**或**添加到主屏幕**。
3. 按浏览器提示确认，然后通过新增的 **UDI Pocket** 图标启动。

Chrome 提供安装提示时，应用中出现的安装按钮可打开浏览器的安装流程。最终安装行为由浏览器决定。[Google Chrome 官方安装说明](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=zh-Hans)。

### iPhone 与 Safari

1. 在 Safari 中打开 [UDI Pocket](https://deepbule0.github.io/UDI/mobile.html?lang=zh-CN)。
2. 打开**共享**；根据 Safari 的布局，可能需要先打开**更多**或页面菜单。
3. 选择**添加到主屏幕**；如出现**作为网页 App 打开**选项，保持启用，然后点击**添加**。

如果找不到该操作，可在共享菜单底部的**编辑操作**中添加。之后通过主屏幕图标启动。[Apple 的 iPhone 官方说明](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/ios)。

## 离线使用与更新

首次访问需要成功联网加载。随后，Service Worker 会缓存构建后的应用及其内置资源。依赖离线使用前，请等待**关于与安装**中提示**可离线使用**；完成主屏幕安装本身不代表缓存已经完整。缓存就绪后，内置工作区、支持的智能体指令、本地修订、本地笔记操作和个人数据集可在断网时使用。分享链接本身携带定义，创建或解析链接无需上传，但接收者仍需能使用应用。通过其他应用发送时取决于该应用的联网条件。社区需要联网获取最新帖子，离线时可显示已保存的帖子和项目示例。公开列出条目需要在线访问 GitHub。

浏览器、设备存储压力或清除网站数据都可能删除缓存。重新联网后可获取新版本；出现更新提示时，点击**更新应用**。可选的 Ollama 桥接服务属于独立的本地开发功能，公开手机演示不提供该服务。

## 保存与迁移的边界

手机和桌面入口使用相同的本地状态键。当它们处于**同一来源、同一浏览器配置及同一存储环境**时，可复用已保存的界面定义、修订历史、当前数据集、授权、笔记和本地活动记录。在一个入口修改后，请刷新另一个入口。不同设备、浏览器配置、隐私浏览环境或托管来源之间不会自动同步。

在 iPhone 上，添加到主屏幕的网页应用与 Safari 的存储相互隔离。因此，安装后的应用可能不会显示此前在 Safari 中创建的工作区。在目标环境打开分享链接可以迁移定义，也可使用高级文件导出与导入；笔记、授权和历史不会随之迁移。这符合 [WebKit 对网页应用存储行为的说明](https://webkit.org/blog/14787/webkit-features-in-safari-17-2/)。

**分享这个界面**会生成携带已校验定义的链接，包含视图、筛选、受支持的组织方式、逻辑数据源、能力请求和操作定义，不包含数据集记录、绑定、授权、笔记、活动或智能体对话。拿到链接的人可读取名称和描述中的自由文本。接收的定义会在解析前从地址栏移除，且不会自动应用。链接上限为 **16,000 字符**，解码定义上限为 **64 KiB**；部分聊天应用的限制更低。当前没有托管短链接或撤销功能，后续编辑不会更新此前发送的副本。

高级界面包工具将同一定义导出或导入为 `.udi.json` 文件，导入上限为 **64 KiB**，也支持粘贴 JSON，便于开发与迁移。分享链接和界面包都不是完整工作空间备份或设备同步机制。

个人记录使用独立的浏览器本地存储，并单独下载为 JSON。导入上限为 **500 KiB**、**每类 200 条记录**、**5 个数据集**，会严格检查字段、有限数值、唯一 ID、日期和提交引用。导入 ID 会被分配到新的 `personal-*` 命名空间。数据下载包含记录，不含笔记或授权。确认删除个人数据集后，本地记录、授权和笔记将永久删除；若删除的是当前数据源，工作区会切回 Aurora。浏览器可能清除本地存储，请为需要保留的数据下载副本。

演示的策略代码和虚构数据都位于浏览器中。添加到主屏幕不会增强这道安全边界。更多限制见[威胁模型](SECURITY.md)和[规范草案](SPECIFICATION.md)。

## 本地运行

```sh
npm ci
npm run dev
```

在 Vite 输出的网址下打开 `/mobile.html?lang=en` 或 `/mobile.html?lang=zh-CN`。生产环境缓存可在构建预览和已发布的 HTTPS 网站中使用；Service Worker 需要安全上下文，localhost 可作为例外。手机访问普通 HTTP 局域网地址时，不属于 localhost 例外。
