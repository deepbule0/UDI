# 本地模型观察记录

[English](../MODEL-OBSERVATIONS.md) | **简体中文**

以下是基于虚构数据的开发阶段冒烟测试观察，不是保留测试集上的评估结果。模型和机器详情记录在 [model-smoke-results.json](../model-smoke-results.json) 中。

1. 使用最初的生成设置时，前两次直接模型调用未返回可解析的 JSON。这些失败保留在 [model-smoke-initial-failure.json](../model-smoke-initial-failure.json) 中。已安装模型声明支持思考。在有界的结构化输出调用中显式关闭思考后，这些用例得到解决；单凭这一观察无法确定空输出的所有成因。
2. 随后的两个直接调用用例生成了预期的筛选与文献库操作，并拒绝了不受支持的发送邮件请求。所选用例和输出记录在结果文件中。
3. 另一次使用未见过措辞的浏览器请求返回了引用不存在面板的提案。语义验证以 “The requested panel is absent from this package”（此包中不存在所请求的面板）拒绝了它；当前界面未发生变化。随后调整了规划器提示词，明确区分新增文献库面板与修改已有面板的可见性。

冒烟测试套件和提示词参与了开发过程，因此不能将成功运行解释为对模型表现的无偏估计。引用验证阻止了这一特定的错误变更被应用，但不能证明有效提案就符合用户意图。未来评估应冻结提示词，使用独立测试集，并保留所有失败。
