# UDI v0.2.0 — UDI Pocket / 手机演示

## English

UDI Pocket brings the interface-package lifecycle to an installable phone web app. It uses the same Core 0.1 package, validator, bounded planner, capability checks, and confirmed local actions as UDI Studio.

- [Phone demo — English](https://deepbule0.github.io/UDI/mobile.html?lang=en)
- [Phone demo — 简体中文](https://deepbule0.github.io/UDI/mobile.html?lang=zh-CN)
- [Desktop demo](https://deepbule0.github.io/UDI/?lang=en)
- [Phone installation and storage guide](https://github.com/deepbule0/UDI/blob/main/docs/MOBILE.md)

The phone UI has Home, Shape, Data, Share, and Activity tabs; experiment cards; provenance sheets; reviewed revisions; independent dataset grants; package export/import/fork; and exact note preview before confirmation. The app shell can reopen offline after successful caching. Android/iPhone installation guidance and English/Chinese screenshots are included.

Local verification on October 17, 2026: 70 unit tests, 19 Edge browser scenarios, three production PWA checks, 16 deterministic intent cases, three lifecycle invariants, type checking, and production build passed. GitHub-hosted validation has not run successfully. Phone tests use touch emulation, not physical iPhone/Android installation testing.

This is an experimental PWA, with no native store binary or device synchronization. The hosted planner is a limited offline parser, and all bundled records are fictional. Browser capability checks demonstrate the architecture rather than secure real services. An iPhone Home Screen app has storage separate from Safari. Existing Core 0.1 packages remain compatible.

## 简体中文

UDI Pocket 将界面包生命周期带到可安装的手机网页应用中。它与 UDI Studio 使用同一份 Core 0.1 界面包、校验器、有界规划器、能力检查，以及经确认的本地操作。

- [手机演示 — 简体中文](https://deepbule0.github.io/UDI/mobile.html?lang=zh-CN)
- [手机演示 — English](https://deepbule0.github.io/UDI/mobile.html?lang=en)
- [桌面演示](https://deepbule0.github.io/UDI/?lang=zh-CN)
- [手机安装与存储指南](https://github.com/deepbule0/UDI/blob/main/docs/zh-CN/MOBILE.md)

手机界面提供首页、塑造、数据、分享、活动五个标签，以及实验卡片、溯源面板、修订审核、独立的数据集授权、界面包导出/导入/派生和确认前的精确笔记预览。应用资源成功缓存后可离线重开，并提供 Android/iPhone 安装说明和中英文截图。

2026 年 10 月 17 日的本地验证通过了 70 项单元测试、19 个 Edge 浏览器场景、3 项生产 PWA 检查、16 个确定性意图用例、3 个生命周期不变量、类型检查和生产构建。GitHub 托管的验证尚未成功运行。手机测试使用触摸模拟，未进行实体 iPhone/Android 安装测试。

这是实验性 PWA，没有原生应用商店安装包或设备同步。托管规划器是有限的离线解析器，内置记录均为虚构。浏览器能力检查用于演示架构，不能为真实服务提供安全保障。iPhone 主屏幕网页应用与 Safari 的存储独立。现有 Core 0.1 界面包继续兼容。
