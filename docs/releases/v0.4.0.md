# UDI v0.4.0 — Personal app experiences / 自己定义的应用体验

## English

UDI is a general framework for people to shape how an app looks, works, and organizes permitted data through an agent and ordinary controls, then share that experience for others to use with their own data. Music, reading, photos, travel, study, and research are illustrative applications. Providers still supply content, supported operations, and a working default app.

This release publishes the [general framework draft](https://github.com/deepbule0/UDI/blob/main/docs/FRAMEWORK.md), proposed requirements, architecture, evidence boundaries, and updated position paper. It is a proposal for public review, not a ratified standard or a claim of compatibility with existing protocols.

- **Personalize:** Agent chat and settings-style controls revise a persistent experience. The hosted demo supports bounded commands; optional local-model planning remains a development feature.
- **Try and use:** Community cards and incoming links show real previews using fictional samples. Choose **Use this interface**, then your workspace and access. Records and notes are preserved; all instance grants are cleared for fresh review.
- **Share effortlessly:** review a name and description, then **Share…** or **Copy link**. No account, file upload, or JSON editing is needed. Opening the link only previews. A link is a copy, not a public community listing or a subscription to later changes.
- **Choose your data:** create a local research workspace through a short form and explicitly allow its requested reading. Writing notes requires separate access and exact-action confirmation. Technical file tools and public GitHub publication are advanced options.

[Desktop](https://deepbule0.github.io/UDI/?lang=en) · [Phone](https://deepbule0.github.io/UDI/mobile.html?lang=en) · [Sharing guide](https://github.com/deepbule0/UDI/blob/main/docs/COMMUNITY.md) · [Music app example](https://github.com/deepbule0/UDI/blob/main/docs/EXAMPLES.md)

Local verification passed **150 unit tests, 46 Edge browser scenarios, 3 production PWA checks, 16 intent cases, and 3 lifecycle invariants**, plus TypeScript and production build. GitHub-hosted validation has not run successfully. Clipboard and public-post interactions are mocked in tests; no real messages or posts are sent.

The executable profile remains **Core 0.1, research only**. Music playback, general workflows, real provider accounts, hosted LLM service, independent-runtime interoperability, and production authorization are not implemented. Links exclude structured personal state but contain public free text: review names and descriptions. Anyone with a link can read it; no short-link or revocation service exists. The phone demo is a PWA, not a native store binary.

## 简体中文

UDI 是一个通用框架：人们通过智能体与常规控件，塑造应用如何呈现、如何工作、如何组织获准使用的数据，并分享这种体验，让其他人配合自己的数据使用。音乐、阅读、照片、出行、学习与研究均可作为说明性应用场景。平台仍提供内容、受支持的操作与可直接使用的默认应用。

本次发布补全了[通用框架草案](https://github.com/deepbule0/UDI/blob/main/docs/zh-CN/FRAMEWORK.md)、拟议要求、架构、证据边界与立场论文。它是供公开讨论的提案，不是已获认可的行业标准，也不声称兼容现有协议。

- **个性化：**智能体对话与设置式控件修订持久体验。托管演示支持有限指令，可选本地模型规划仍属于开发功能。
- **试用与使用：**社区卡片和接收链接提供基于虚构示例的真实预览。选择**使用这个界面**，再选择自己的工作空间及访问。记录与笔记保留，全部实例授权清空以重新审阅。
- **简单分享：**审阅名称与介绍后，使用**分享…**或**复制链接**。无需账户、文件上传或 JSON 编辑。打开链接只预览。链接是副本，不会自动公开上架，也不订阅后续修改。
- **选择数据：**通过简短表单创建本地研究工作空间，明确允许所请求的读取。写笔记仍需独立权限及具体操作确认。技术文件工具与公开 GitHub 发布位于高级选项。

[桌面版](https://deepbule0.github.io/UDI/?lang=zh-CN) · [手机版](https://deepbule0.github.io/UDI/mobile.html?lang=zh-CN) · [分享指南](https://github.com/deepbule0/UDI/blob/main/docs/zh-CN/COMMUNITY.md) · [音乐应用示例](https://github.com/deepbule0/UDI/blob/main/docs/zh-CN/EXAMPLES.md)

本地验证通过 **150 项单元测试、46 个 Edge 浏览器场景、3 项生产 PWA 检查、16 个意图用例及 3 个生命周期不变量**，以及 TypeScript 与生产构建。GitHub 托管验证尚未成功运行。测试模拟剪贴板与公开发帖交互，不发送真实消息或帖子。

可执行配置仍为 **Core 0.1，仅限研究领域**。尚未实现音乐播放、通用工作流、真实平台账户、托管大模型服务、独立运行时互操作或生产授权。链接不携带结构化个人状态，但包含公开自由文本，请检查名称及介绍。持有链接的人都可以读取，没有短链接或撤回服务。手机版是 PWA，不是原生应用商店安装包。
