# UDI v0.3.0 — Agent, Data & Community / 智能体、数据与社区

## English

This release makes the UDI authoring and sharing lifecycle visible in both desktop Studio and phone Pocket.

UDI proposes apps that provide data, supported capabilities, and a default interface users can reshape through Agent chat, ordinary controls, or community-shared definitions. The bilingual [music-app example](https://github.com/deepbule0/UDI/blob/main/docs/EXAMPLES.md) explains that model; the shipped reference demo remains research-specific.

- **Agent:** conversation and a settings-style Controls mode manage interface revisions, source binding, and permissions through the same reviewed state transition. Try `Use Atlas lab`, `Revoke experiment access`, or `Show only failed experiments`.
- **Data:** distinguish platform samples from personal research JSON; import into a fresh local instance with no grants, review access, download records, and confirm deletion.
- **Community:** browse/search validated public GitHub posts, preview and install/fork an interface, or review your definition and prepare a public post. Project starter examples are clearly labeled. Final publication requires signing in and submitting on GitHub.

[Open Agent](https://deepbule0.github.io/UDI/mobile.html?lang=en&view=agent) · [Open Community](https://deepbule0.github.io/UDI/mobile.html?lang=en&view=community) · [Desktop](https://deepbule0.github.io/UDI/?lang=en) · [Community/data guide](https://github.com/deepbule0/UDI/blob/main/docs/COMMUNITY.md)

Local checks on October 17, 2026 passed 133 unit tests, 35 Edge browser scenarios, three production PWA checks, 16 deterministic intent cases, and three lifecycle invariants, plus type checking and production build. Community tests mock GitHub data and the composer; they do not create real posts or test GitHub sign-in/submission. The public feed is subject to GitHub rate limits and shows cached/unavailable states with a direct GitHub browsing link.

The hosted Agent is a bounded offline command assistant. Optional local-model planning remains a development feature. Personal records stay in this browser; interface sharing excludes instance records, grants, notes, bindings, and chat history. Review all free text before posting. Core schema stays `0.1`. The music-app use case is now explained in both languages; audio playback and arbitrary app generation are not implemented.

## 简体中文

此版本在桌面 Studio 与手机 Pocket 中，将 UDI 的创作、数据管理和分享流程变为可见、可操作的功能。

UDI 提出一种应用模型：平台提供数据、受支持的能力与默认界面，用户通过智能体对话、常规控件或社区共享的定义调整界面。中英文[音乐应用示例](https://github.com/deepbule0/UDI/blob/main/docs/zh-CN/EXAMPLES.md)说明该模型；已发布的参考演示仍限于研究领域。

- **智能体：**对话和设置式控制面板通过同一个审核后的状态转换机制，管理界面修订、数据绑定和权限。可尝试 `切换到 Atlas lab`、`撤销实验访问权限` 或 `只显示失败实验`。
- **数据：**区分平台示例与个人研究 JSON；导入为无初始授权的独立本地实例，审阅访问、下载记录并确认删除。
- **社区：**浏览和搜索通过校验的公开 GitHub 帖子，预览并安装或派生界面，或审核自己的定义并准备公开帖子。项目示例有明确标识，最终发布需在 GitHub 登录并提交。

[打开智能体](https://deepbule0.github.io/UDI/mobile.html?lang=zh-CN&view=agent) · [打开社区](https://deepbule0.github.io/UDI/mobile.html?lang=zh-CN&view=community) · [桌面版](https://deepbule0.github.io/UDI/?lang=zh-CN) · [社区与数据指南](https://github.com/deepbule0/UDI/blob/main/docs/zh-CN/COMMUNITY.md)

2026 年 10 月 17 日的本地检查通过了 133 项单元测试、35 个 Edge 浏览器场景、3 项生产 PWA 检查、16 个确定性意图用例、3 个生命周期不变量，以及类型检查与生产构建。社区测试模拟 GitHub 数据和编辑器，不创建真实帖子，也不验证 GitHub 登录及最终提交流程。公开动态受到 GitHub 限流影响，界面会标注缓存或不可用状态，并提供直接在 GitHub 浏览的链接。

托管智能体是有限的离线指令助手，可选本地模型仍属于开发功能。个人记录保存在此浏览器；界面分享不包含实例记录、授权、笔记、绑定或对话历史。发布前请检查所有自由文本。Core 格式仍为 `0.1`。中英文说明已补充音乐应用用例，但尚未实现音频播放或任意应用生成。
